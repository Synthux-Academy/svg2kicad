How it works

  1. In Illustrator, put each part on its own layer, named:
    • EdgeCuts – board outline
    • TouchCopper – touch pad, exposed copper (F.Cu + F.Mask + keep-out)
    • TouchBlack – touch pad under solder mask (F.Cu + keep-out)
    • LEDWindow – LED window (F.Mask + B.Mask + keep-out)
    Artwork on any other layer uses the Artwork layer setting (F.Mask by default). Hidden layers are ignored.
  2. Export as SVG with Object IDs set to Layer Names, and Decimal Places at 3 or higher — 1 decimal place rounds coordinates to ~0.035mm steps, which shows up as flats on circles (e.g. a round touch pad cut from an LED window won't line up).
  3. Drop the SVG on the Source panel (or click it to browse), check the KiCad preview, then copy and paste into KiCad's PCB editor (Ctrl/Cmd+V).

A PNG works too: its dark areas become artwork (Artwork layer or LED window setting), light areas inside them stay holes, and there's no board outline. Its size comes from the PNG's DPI (72 if it has none); set Output size to change it.
